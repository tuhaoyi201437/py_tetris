# 俄罗斯方块（Tetris）

一个用 **Python 标准库 `tkinter`** 实现的经典俄罗斯方块游戏，**零第三方依赖**，开箱即玩。

---

## 特性

- **7 种标准方块**（I / O / T / S / Z / J / L），各配独立颜色
- **旋转系统**：↑ / X 顺时针、Z 逆时针，带**墙踢（wall kick）**，贴墙也能转
- **下落控制**：↓ 软降、空格 硬降（直接落底）、自动定时下落（速度随等级提升）
- **幽灵投影**：半透明显示当前方块落点，方便规划落位
- **消行计分**：单/双/三/四消分别得 100 / 300 / 500 / 800 分（再乘以当前等级）；每消 10 行升一级，下落加速
- **粒子特效**：方块消除时迸发彩色粒子，带重力与淡出
- **塌落动画**：被消行上方的方块会平滑下落填补空隙
- **右侧信息面板**：下一个方块预览、分数、等级、消行数
- **开始界面**：启动后显示「开始游戏」覆盖层，**点击按钮或按回车**进入；开始前方块不自动下落、也不接受操作输入
- **退出按钮**：游戏内面板底部「退出」按钮（或 Alt+W）可直接关闭窗口
- **设置面板**：面板底部「设置」按钮打开设置窗口，可调整**粒子数量**（每格 0–12，0 = 关闭特效）与切换**彩色 / 黑白**配色；**打开设置时方块自动暂停下落**，关闭后从原状态继续
- **彩色 / 黑白模式**：面板底部「彩色模式 / 黑白模式」按钮随时切换；黑白模式下**背景纯黑、方块统一深灰、按钮深灰**，黑色背景上的文字为深灰、深灰按钮上的文字为黑色
- **圆角按钮**：开始游戏、设置、彩色/黑白切换、退出以及设置窗口的「确定 / 取消」均采用圆角样式（Canvas 自绘圆角矩形 + 文字 + 悬停高亮）
- **设置本地记忆**：当前配色与粒子数量自动保存到 `tetris_settings.json`，下次启动自动套用
- **暂停 / 重开** + 游戏结束弹窗

## 运行方法

### 方式一：双击启动（推荐）

直接双击 `run.bat` 即可。它会调用 PATH 中的 `python` 运行 `tetris.py`。

> 前提：你的机器上 `python` 已加入环境变量，且为带有 `tkinter` 的 Python 3.x（Windows 版官方 CPython 自带）。  
> 若双击后提示 “'python' 不是内部或外部命令”，说明 PATH 未配置 `python`，请用方式二。

### 方式二：命令行启动

```bash
cd /path/to/俄罗斯方块
python tetris.py
```

若系统有多个 Python，可指定完整路径，例如：

```bash
"C:\Users\你的用户名\AppData\Local\Programs\Python\Python313\python.exe" tetris.py
```

## 操作说明

| 按键      | 作用            |
| ------- | ------------- |
| ← / →   | 左右移动          |
| ↓       | 软降（加速下落，得分加成） |
| 空格      | 硬降（直接落到底部）    |
| ↑ / X   | 顺时针旋转         |
| Z       | 逆时针旋转         |
| P       | 暂停 / 继续       |
| Esc     | 暂停 / 继续       |
| R       | 重新开始          |
| 回车      | 开始游戏（在开始界面时）  |
| 退出按钮   | 关闭游戏（面板底部按钮） |
| 设置按钮   | 打开设置窗口（粒子数量 / 彩色·黑白） |
| 彩色/黑白按钮 | 切换经典彩色 / 黑白（黑底灰块）配色 |
| Alt + W | 关闭游戏          |

> 提示：`Esc` 与 `P` 都可用于暂停；开始界面下按「回车」或点击「开始游戏」按钮进入游戏；关闭窗口可用面板「退出」按钮或 `Alt+W`；面板「设置」按钮可调整粒子数量与配色，调整即时保存并记忆到本地，**打开设置窗口时方块会自动暂停下落**，关闭后继续。

## 计分与等级

| 一次消除行数      | 得分       |
| ----------- | -------- |
| 1 行         | 100 × 等级 |
| 2 行         | 300 × 等级 |
| 3 行         | 500 × 等级 |
| 4 行（Tetris） | 800 × 等级 |

- 每累计消除 **10 行** 升一级
- 等级越高，方块自动下落越快（`fall_speed = max(80, 500 − (等级−1) × 40)` 毫秒）

## 常见问题

**Q：能加音效 / 连击加分吗？**  
A：目前未实现。可在此基础上扩展——`tetris.py` 的 `Tetris` 类负责游戏逻辑、`TetrisGUI` 负责渲染与特效，新增逻辑相对独立。

---

## 实现说明（对开发者）

- `Tetris` 类：**纯游戏逻辑**，不依赖任何 UI。包含棋盘、当前/下一个方块、旋转状态、消行、计分、等级、塌落动画状态机（`play` / `clearing`）。
- `TetrisGUI` 类：**tkinter 渲染与交互**。负责画布绘制、粒子系统、键盘绑定与主循环；配色由 `THEMES` 主题表管理（`classic` 彩色 / `dark` 纯黑底＋深灰方块＋深灰按钮），渲染统一经 `_color_of(name)` 取色，面板「彩色/黑白模式」按钮调用 `_toggle_theme` / `_set_theme` 切换。所有按钮均为 Canvas 自绘的**圆角矩形**（`_round_rect` + `_make_round_button`），支持点击与悬停高亮，配色由 `_btn_colors` 按主题返回。
- **设置与本地记忆**：模块级 `load_settings()` / `save_settings()` 读写 `tetris_settings.json`（字段 `particle_count` 0–12、`theme` 为 `classic`/`dark`）。`TetrisGUI.__init__` 启动时加载并设置初始配色与粒子数；面板「设置」按钮（`_build_setting_button` + `_open_settings`）提供滑块调粒子数量、单选切换彩色/黑白，确认后写盘并即时套用。**打开设置时 `settings_open` 置真，主循环 `_loop` 跳过 `tick` 使方块暂停下落，关闭后恢复。**
- 粒子数量由 `TetrisGUI.particle_count` 控制（来自设置），`spawn_clear_particles` 按此值为每格生成粒子；设为 0 即关闭特效。
- 开始界面：`_show_start_screen` 生成覆盖层（标题 + 圆角「开始游戏」按钮 + 操作提示），`started` 状态门控——开始前不自动下落、输入经 `_safe` 包装忽略；点击按钮或回车调用 `_start_game`（幂等）进入游戏。面板底部圆角「退出」按钮（`_build_quit_button`）与 `Alt+W` 均可关闭窗口。
- 旋转采用 7 种方块的 `ROTATIONS` 表，每步均为标准 90° 旋转（含墙踢）。

> 为何不用 pygame：本环境无法便捷安装 pygame（Python 3.13 缺预编译 Windows 轮子），故改用标准库 `tkinter`，保证用户无需安装任何依赖即可运行。
